lxask

Forgot the command? Just ask.

A Linux command assistant that runs on your own machine: no API key, no cloud, no account. Ask in plain words, get the command, with every part explained from the documentation.

Get started Read the docs GitHub
$curl -fsSLO https://github.com/arxhr007/lxask/releases/latest/download/install.sh && sh install.sh

What it does for you

A small model, the tldr pages and the man pages, checked against each other, on your laptop.

🔒

Private and offline

Everything runs locally on your CPU. Nothing you ask leaves your machine, and after installing it needs no network.

⚡

Small and fast

About 1 GB, no GPU. About 2 seconds an answer once loaded, and the installer offers to keep it loaded for you.

✅

Checks its own work

Every command is checked against the man pages and tldr, and whatever it cannot confirm is marked unverified.

⌨️

Right on your prompt

Type what you want, press Ctrl+G, and the line becomes the command, ready to edit. Nothing runs until you press Enter.

🧭

Keeps your restrictions

“Without lsof”, “don't use sudo”: it answers with something else. A vague request gets a question back, not a guess.

🛡️

Never runs a command for you

It suggests; you decide. Anything that deletes, overwrites or formats carries a warning.

How good is it

Measured on questions it was never trained on. When it misses, it is usually by a detail: a flag, a field number.

96-99%right program on everyday questions it was never trained on (150)
87%of hand-written file and text tasks work as run in a sandbox (46)
75%of a harder generated set work as run (200)
~2 sper answer once loaded; about 7 s from cold

Quick start

Linux on x86_64 or ARM64 with glibc 2.28 or newer.

bash
curl -fsSLO https://github.com/arxhr007/lxask/releases/latest/download/install.sh
sh install.sh        # about 1.1 GB, once; no root needed
bash
lxask "which process uses port 3000, without lsof or netstat"
# $ ss -ltnp 'sport = :3000'
bash
eval "$(lxask --shell-init bash)"     # in ~/.bashrc: then type a request and press Ctrl+G
